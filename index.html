    À propos d'OmniNote
    
    
    Un éditeur de texte où les blocs de code s'exécutent, dans une machine Linux émulée par votre navigateur.
    
    
    OmniNote est un outil s'exécutant intégralement dans votre navigateur. Aucune donnée ni aucun document n'est transmis, stocké ou consulté par un serveur. La personne qui génère et partage un lien est seule responsable de son contenu.
    
    
      
      
    • Vos documents restent dans ce navigateur ; un lien contient le document lui-même, rien n'est déposé ailleurs.
      • 
      
    • La machine virtuelle n'a pas de carte réseau : les programmes qu'elle exécute n'atteignent rien en dehors de la page.
      • 
      
    • Un document reçu par lien n'exécute pas son HTML ni ses exécutions automatiques sans votre accord.
      • 
      
    • OmniNote ne vous demandera jamais de mot de passe ni d'information de paiement.
      •

    Partager par lien
    
    
    Tout le document tient dans l'adresse : le texte, le code et ses résultats. Rien n'est enregistré sur un serveur ; qui a le lien a le document. Vous êtes seul responsable du contenu que vous partagez.
    
    
    
    
    
    
    
    
    
    
      
      
      
    
    
      

  
    
    Versions du document
    
    
    Une version est gardée à chaque pause d'écriture qui change le texte (au plus une par minute, sauf un gros changement), dans ce navigateur seulement. Chacune se rouvre, se restaure, ou devient un lien à envoyer.
